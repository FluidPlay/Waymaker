# Waymaker

Waymaker is a self-contained spline-based road/path surface generator for **s&box**. Drop the `Waymaker` component on a GameObject, author a spline with Waymaker's own editor tool, and the component procedurally builds a textured quad-strip mesh (with optional end caps) as a generated child object. It depends only on engine APIs (`Sandbox.Spline` and friends) — no RoadTool, RailTool, or third-party tooling required.

## Supported engine

- **s&box** (developed and verified against engine build `26.09.22b`, .NET 10 / C# 14).
- Uses the standard s&box component, editor-tool, and shader systems; no engine patches needed.

## Features

- Editor-only procedural mesh generation with dirty-flag rebuilds and automatic cleanup of generated children.
- Closed (looped) or open splines with four tangent modes: **Auto**, **Linear**, **Mirrored**, **Split**.
- Two V-tiling modes (dynamic world-length tiling or fixed integer tiles), horizontal tiling and padding.
- Optional start/end **caps** with independent materials (fixed-tiling, non-looped splines only).
- **Minimum Edge Length** merging so tight turns keep the full surface width instead of collapsing inward.
- A custom complex/PBR shader (`waymaker/shaders/waymaker_complex.shader`) with a **Translucent** option and a selectable alpha source: the color texture's own alpha or a separate translucency mask.
- Full undo/redo integration in the spline editor, plus unit-tested mesh building (MSTest).

## Quick setup

1. **Install** the folders above and let the s&box editor recompile the Code and Editor assemblies.
2. In a scene, create (or select) a GameObject and **add the `Waymaker` component** (icon: `route`). It starts with a 3-point spline.
3. **Assign a Source Material** under the *Surface* section — generation is skipped until one is set. For translucent roads, use one of the sample materials in `Assets/Waymaker/Materials/`.
4. Select the GameObject and activate the **Waymaker Splines** editor tool (toolbar, alias `waymaker_splines`). A floating **Waymaker Spline Editor** window appears.
5. Edit the spline: drag point handles in the viewport, click a segment to insert a point, Shift-drag a point to extend the spline, or use the window's control sheet and buttons.
6. The mesh regenerates automatically into a child GameObject named **`Waymaker Surface`** (tagged `waymaker_generated_mesh`). Toggle the editor camera's **Wireframe** mode to preview the generated quad topology.

## The Waymaker component (inspector)

All properties are grouped into sections via `Feature(...)` groups.

### Waymaker

| Property | Type | Default | Description |
|---|---|---|---|
| `Spline` | Spline (hidden) | 3 seeded points | The underlying spline data. Hidden in the inspector — edit it with the Waymaker Splines tool. Null-safe: assigning null resets it to a fresh spline. |

### Spline

| Property | Type | Default | Description |
|---|---|---|---|
| **Loop** | bool | `false` | Closes the spline into a loop. Rejected while the spline has fewer than 2 points. Looped splines disable caps. |

### Surface

| Property | Type | Default | Description |
|---|---|---|---|
| **Source Material** | Material | — | Material applied to the generated surface. Required — a warning is logged while unassigned. |
| **Surface Width** | float | `500` | Width of the generated strip in world units (clamped to ≥ `0.01`). |

### Texturing

| Property | Type | Default | Description |
|---|---|---|---|
| **Dynamic V Tiling** | bool | `true` | On: tiles V by world distance along the path. Off: uses a fixed integer tile count. |
| **Dynamic V Tile Length** | float | `500` | World length of one V tile (shown only in dynamic mode; clamped to ≥ `0.1`). |
| **Vertical Tiles** | int | `1` | Total number of V repeats over the whole path (shown only in fixed mode; clamped to ≥ `1`). |
| **Horizontal Tiling** | float | `1.0` | Number of U repeats across the width (clamped to ≥ `0.01`). |
| **Horizontal Padding** | float | `0.0` | `0..1` share of the generated width excluded from the main texture (inward UV padding on both sides). |

### Caps

Caps only appear for **fixed-tiling, non-looped** splines.

| Property | Type | Default | Description |
|---|---|---|---|
| **Cap Texture** | bool | `false` | Enables start/end caps. |
| **Cap Texture Start** | Material | — | Material for the start cap (falls back to Source Material). |
| **Cap Texture End** | Material | — | Material for the end cap (falls back to Source Material). |
| **Cap Length** | float | `100` | Length of each cap along the path (clamped to ≥ `0`, and to at most half the path length on short splines). |

### Geometry

| Property | Type | Default | Description |
|---|---|---|---|
| **Minimum Edge Length** | float | `0.01` | Quads whose longitudinal edges are shorter than this get merged (or skipped on tight turns) so the surface never narrows. Values above `0.1` trigger a warning about coarser quads. *Serialized as `MinimumEdgeWidth`; the name is kept for scene compatibility.* |

### Behavior notes

- Generation happens **in the editor only** (`Component.ExecuteInEditor`); rebuilds are triggered by spline changes and property validation, then flushed on the next editor update.
- The generated child is created with `SmoothingAngle = 40` and destroyed automatically when the component is disabled.
- Local bounds = spline bounds expanded by half the surface width (used for culling/selection).

## The Waymaker Spline Editor (editor tool)

Activate **Waymaker Splines** (alias `waymaker_splines`) while a Waymaker object is selected. The tool opens a floating window (dockable overlay, max width 500) titled `Waymaker Spline Editor - <object>`, with an **info** button (usage tooltip) and a **close** button (the window collapses to a small route icon you can re-open).

### Control sheet (selected point)

| Row | Description |
|---|---|
| **Tangent Mode** | `Auto` / `Linear` / `Mirrored` / `Split` for the selected point. |
| **Position** | World position of the point. |
| **In** / **Out** | Tangent control handles — editable only in **Mirrored** and **Split** modes; disabled in Auto/Linear. |

### Advanced group (collapsible)

| Row | Description |
|---|---|
| **Roll (Degrees)** | Twist of the surface frame around the tangent. |
| **Scale (_, Width, Height)** | Per-point width/height scale (default `1,1,1`). |
| **Up Vector** | Custom up direction for the frame (default `0,0,1`). |

### Button row

| Button | Action |
|---|---|
| ⏮ | Go to previous point |
| ⏭ | Go to next point |
| 🗑 | Delete point (a minimum of two points is always kept) |
| ➕ | Insert a point after the current one (mid-segment, or extends the spline at the end) |

### 3D gizmos

- **Segments** are clickable hitboxes — click to insert a point at the closest position.
- **Point handles** are solid boxes (cyan when hovered/selected); the selected point also shows In/Out tangent handles (hidden in Linear mode). **Shift-drag** a point to extend the spline with a new point.
- Moving a tangent automatically promotes `Auto` → `Mirrored` (and mirrors Out = −In, or vice versa).
- Handle orientation follows the local frame (tangent + up + roll), or global axes when global space is enabled.
- All edits push named undo scopes: `Update/Add/Delete/Move Waymaker Spline Point`.
- **Wireframe preview**: the generated mesh's quad topology is drawn in cyan, but only while the scene's `editor_camera` has **Wireframe Mode** enabled.

## Material & shader

The custom shader lives at `Assets/Waymaker/Shaders/waymaker_complex.shader` (shader name `waymaker/shaders/waymaker_complex.shader`). It's a complex/PBR surface shader with these extras:

| Feature | Values | Meaning |
|---|---|---|
| `F_TRANSLUCENT` | `0` / `1` | Enables alpha blending and disables depth writes (standard s&box translucency state). |
| `F_WAYMAKER_ALPHA_SOURCE` | `0 = Color Texture Alpha`, `1 = Translucency Mask (R)` | Where opacity comes from: the alpha channel of `TextureColor`, or the red channel of `TextureTranslucency`. |
| `g_flOpacityScale` | float | Global opacity multiplier applied when translucent (e.g. `0.424` for a subtle overlay). |

Texture slots:

- **`TextureColor`** — base color; its **alpha channel is preserved** (RGBA) so PNG cutouts work directly.
- **`TextureTranslucency`** — separate grayscale mask; its **red channel** is used as opacity when the alpha source is set to the mask.

Sample materials in `Assets/Waymaker/Materials/`:

- `desertpath_1024_alpha.vmat` — translucent (`F_TRANSLUCENT 1`), alpha from the color PNG, `g_flOpacityScale 0.424`.
- `waymaker_alpha_check.vmat` — translucent, alpha from `DesertPath_mask.png`, `g_flOpacityScale 1.0`.

> Tip: in the Material Editor, disable **Override** if the preview doesn't seem to reflect saved material changes.

## Mesh generation details (for advanced users)

`WaymakerMeshBuilder.Build(spline, settings, sampleSpacing)` returns a `PolygonMesh` (or `null` for degenerate input):

- Samples the spline at fixed spacing (40 units), at every control point, and exactly at cap boundaries.
- Builds a quad strip with explicit UVs: U from `GetMainURange(tiling, padding)`, V from dynamic centerline distance or fixed-path fraction.
- Caps use independent `0..1` V coordinates over their length and the same horizontal tiling and padding as the main surface. They use their assigned cap material, falling back to the source material.
- `MergeShortEdges` enforces **Minimum Edge Length** while preserving exact cap boundaries and full width on turns.
- Every face is assigned an explicit white vertex color so translucent shaders can't resolve to zero alpha.

Unit tests: `UnitTests/WaymakerMeshBuilderTests.cs` (10 MSTest cases) covers UV padding, both tiling modes, cap eligibility/clamping, loops, and the minimum-edge-length behavior on straight and tight-turn sections.
